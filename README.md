**Beitrag zum 37. Europäischen Wettbewerb 1990**

Die pdf Datei enthält einen Aufsatzbeitrag zum 37. Europäischen Wettbewerb 1990 mit "Redaktionsschluss" 1. Februar 1990. Dieser Beitrag wurde mit einer Teilnahme an der internationalen Preisträgerbegegnung im Sommer 1990 auf Zypern ausgezeichnet. (Siehe auch Segeberger Nachrichten vom 12. Mai 1990.)

Der Europäische Wettbewerb ist ein in vielen Ländern Europas an Schulen ausgetragener Wettbewerb.
